>Claude Code あんちょこ

★ 定番　／　/ で一覧　? でショートカット表示

入力

/★コマンド一覧
@★ファイルを指定
!★シェルを直接実行
Shift+Enter★改行
Ctrl+V画像を貼る
Ctrl+Gエディタで長文を書く

権限モード（Shift+Tab）

default毎回確認
acceptEdits編集は自動でOK
plan読むだけ・計画を出す
auto安全な操作は自動

キー操作

Esc★Claude を止める
Esc Esc★巻き戻し
Shift+Tab★権限モード切替
Ctrl+C中断／入力を消す
Ctrl+D終了（2回）
↑ ↓入力履歴
Ctrl+R履歴を検索
Ctrl+S書きかけを退避／戻す
Ctrl+O詳細表示
Ctrl+TToDo を表示
Ctrl+B実行中を裏に回す
Option+Pモデル切替
Ctrl+L画面を描き直す

会話の管理

/clear★リセットして新規
/compact★要約して文脈を空ける
/resume★過去の会話を再開
/rewind★前の時点に戻す
/context文脈の使用量
/btw会話に残さず質問
/rename会話に名前を付ける
/copy最後の返答をコピー

作業

/plan★計画モードで始める
/init★CLAUDE.md を作る
/memory★CLAUDE.md を編集
/diff変更を確認
/code-review変更をレビュー
/tasks裏の作業を見る

設定・確認

/model★モデルを選ぶ
/usage★使用量・上限
/effort考える深さ
/permissions許可ルール
/config設定画面
/doctor不具合を診断
/mcpMCP を管理

ターミナルから

claude★対話を始める
claude -c★直前の会話を続ける
claude -r★会話を選んで再開
claude -p "…"一発で答えて終了
claude update最新版に更新
